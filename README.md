# Simple Interest Calculator

A simple calculator that calculates the simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (P × R × T) / 100

Where:

- P = Principal Amount
- R = Rate of Interest
- T = Time Period

## Example

If:

- Principal = ₹10,000
- Rate = 5%
- Time = 2 years

Then:

Simple Interest = (10000 × 5 × 2) / 100

Simple Interest = ₹1,000

## Features

- Calculates simple interest
- Easy to use
- Takes principal, rate, and time as inputs
- Displays the calculated interest
